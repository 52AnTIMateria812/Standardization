# Программный комплекс «Как привезли»

## Telegram-бот с веб-интерфейсом заказа итальянских продуктов

**Техническое задание по ГОСТ 19.201-78**  
**Год:** 2026

## 1. Введение

Документ задаёт требования к кроссплатформенному программному комплексу: чат-боту для Telegram и встроенному приложению Telegram Web App.

Полное наименование: «Telegram-бот с веб-интерфейсом заказа итальянских продуктов „Как привезли“». Краткое наименование: программный комплекс «Как привезли».

## 2. Основания для разработки

Основанием указана учебная/производственная практика, утверждённая колледжем 16.06.2026.

## 3. Назначение разработки

Система должна знакомить пользователей с ассортиментом аутентичных итальянских продуктов и обеспечивать выбор и оформление заказа. Чат-бот выполняет информационные функции, а Telegram Web App предоставляет интерфейс магазина без перехода на внешний сайт.

## 4. Требования к программе

### 4.1 Функциональные характеристики

Комплекс состоит из текстового бота и встроенного веб-приложения.

#### 4.1.1 Чат-бот

- Команда `/start` приветствует пользователя, кратко представляет сервис и сообщает об оплате и доставке.
- Постоянное меню содержит кнопки «Открыть магазин», «О сервисе» и «Контакты / Поддержка».
- «Открыть магазин» запускает Web App; «О сервисе» показывает сведения о происхождении продуктов и гарантиях качества; пункт поддержки выдаёт контакт администратора.
- Бот уведомляет пользователя об изменении статуса заказа, например о завершении сборки или передаче курьеру.

#### 4.1.2 Telegram Web App

- Каталог разделён на категории, например пасту, сыры, мясные деликатесы и оливковое масло.
- Карточка товара содержит изображение, название, описание, вес или объём и текущую цену.
- Корзина позволяет добавлять и удалять позиции, менять количество и автоматически пересчитывает итог.
- При оформлении клиент вводит имя, телефон и адрес доставки.
- Перед отправкой приложение проверяет поля, затем закрывается и передаёт боту состав корзины и данные доставки для формирования итогового чека.

### 4.2 Надёжность

Программа должна обрабатывать исключения и переживать временную потерю связи с Telegram API без аварийного завершения. При некорректных контактных данных интерфейс показывает предупреждение и не отправляет форму. База данных резервируется не реже одного раза в сутки.

### 4.3 Условия эксплуатации

Серверная часть размещается на удалённом сервере и работает постоянно. Непрерывное присутствие технического сотрудника возле сервера не требуется.

### 4.4 Технические средства

Минимальные параметры сервера из исходного задания:

- процессор: 1 ядро от 1,5 ГГц;
- оперативная память: не менее 1 ГБ;
- свободное место: не менее 5 ГБ;
- постоянное подключение к интернету от 10 Мбит/с.

Клиентские устройства должны соответствовать требованиям официального приложения Telegram для Android, iOS, Windows, macOS или Linux.

### 4.5 Информационная и программная совместимость

- Серверная ОС: Linux (например, Ubuntu Server 22.04 LTS или новее) либо Windows 10/11.
- Среда бота: Python 3.10+ и библиотеки интеграции с API.
- Web App: HTML5, CSS3 и JavaScript с Telegram Web Apps API.
- СУБД: SQLite.
- Интерфейс должен адаптивно отображаться во встроенном WebView Telegram на мобильных и настольных платформах.

## 5. Требования к программной документации

В комплект входят:

- настоящее техническое задание по ГОСТ 19.201-78;
- пояснительная записка по ГОСТ 19.404-79 с архитектурой, схемой данных и интеграцией Web App с ботом;
- руководство оператора по ГОСТ 19.505-79 с установкой, запуском сервера и работой с программой.

## 6. Технико-экономические показатели

Экономическая эффективность отдельно не рассчитывается из-за учебно-практического характера проекта. Ожидаемый эффект связан с автоматизацией общения с покупателями, представлением каталога и ускорением оформления заказов.
