# Работа с ГОСТами

В этой папке можно хранить перечень применимых стандартов, ссылки на официальные источники и собственные заметки по их применению.

При ссылке на стандарт сохраняйте его обозначение и официальное название без изменений. Перед использованием проверяйте актуальность редакции, область применения и наличие изменений по официальному каталогу или иному уполномоченному источнику.

Полные тексты стандартов размещайте только при наличии права на их распространение. В учебных материалах достаточно привести точную библиографическую ссылку и пояснить, какие положения необходимо проверить.
